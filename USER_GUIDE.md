# CNLA IDS - User Guide

## 📋 Overview

CNLA IDS is a Network Intrusion Detection System that monitors network traffic and detects potential security threats in real-time.

## 🚀 Installation

### Prerequisites
- Python 3.8 or higher
- pip (Python package manager)
- Git (for cloning the repository)

### Step 1: Clone the Repository
```bash
git clone https://github.com/friedfossil/cnla-project.git
cd cnla-project
