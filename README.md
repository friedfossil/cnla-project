#  Real-Time Network Packet Monitoring & Rule-Based Intrusion Detection System

##  Project Overview
A lightweight, real-time network intrusion detection system that captures live network packets, applies predefined security rules, and displays alerts via a Flask-based web dashboard.

##  Features
-  Real-time packet capture using Scapy
-  Rule-based detection (Port Scanning, ICMP Flood, High Packet Rate)
-  Live web dashboard with Flask
-  CSV logging for alerts and packet data
-  Simulation mode for testing without root permissions
-  Lightweight and beginner-friendly

##  Technologies Used
- **Python** - Core programming language
- **Flask** - Web framework for dashboard
- **Scapy** - Packet capture and analysis
- **HTML/CSS/JS** - Frontend dashboard
- **GitHub Codespaces** - Cloud development environment
